SadServers Labs 

My practical Linux troubleshooting exercises using "SadServers" (https://sadservers.com/).

This repository contains my notes and solutions for the different scenarios I complete.

Objectives

- Improve Linux system administration skills.
- Develop troubleshooting and problem-solving abilities.
- Understand Linux processes, services, logs and system resources.
- Document commands, investigations and solutions.
